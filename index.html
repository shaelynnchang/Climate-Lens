ClimateLens

Understanding CO2 emissions through machine learning.

About the Project

ClimateLens is a machine learning project that uses historical CO2 emissions data to classify countries into high and non-high emission categories.

A Random Forest Classification algorithm analyzes historical patterns to generate predictions for 2023.

Research Question

Can machine learning predict whether a country's CO2 emissions will exceed a historical high-emission threshold using its previous three years of data?

Methodology

  1. Historical CO2 emissions data collection.
  2. Data cleaning and preprocessing.
  3. Feature engineering using three previous years.
  4. Random Forest Classification training.
  5. Model evaluation and 2023 predictions.

Limitations

Predictions are based on historical patterns and do not account for every factor affecting emissions. Classification results should not be interpreted as actual measured 2023 emissions.
